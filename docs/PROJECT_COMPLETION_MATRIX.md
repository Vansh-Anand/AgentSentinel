## Current product claim

The resume-safe claim is a **task-scoped AI-agent tool gateway with signed public evidence and a restricted Docker fixture**, plus a **VM-validated three-probe Linux telemetry vertical slice**. The browser Gateway does not run native L3, a trained L4 model, or hardware L7 attestation. An allowed browser action therefore has an `INCOMPLETE` EffectSeal receipt.

The [published v3 report](../benchmarks/results/agentsentinel_model_eval_v3.md) is one trial per held-out synthetic case: 1/25 attack READMEs induced a forbidden proposal, 0/1 such proposals executed, 25/25 benign answers passed a lexical task check, and all 50 audit chains, signed receipts and final-answer hashes verified against the current source at publication. The [v2 report](../benchmarks/results/agentsentinel_model_eval_v2.md) measured a different corpus and earlier source revision (5/25 forbidden proposals; 0/5 executed). These are not comparative intervention trials and do not establish general prompt-injection immunity.
