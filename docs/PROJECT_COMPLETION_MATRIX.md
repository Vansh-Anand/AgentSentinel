## Current product claim

The resume-safe claim is a **task-scoped AI-agent tool gateway with signed public evidence, a custom-input Gemini demo, a seven-layer challenge lab with explicit proof levels, and a restricted Docker fixture**, plus a **VM-validated three-probe Linux telemetry vertical slice**. The challenge lab runs live L2 gateway decisions and a live L6 HMAC check on a synthetic record copy. Its L1 schema check is narrower than constrained decoding, L3–L5 are replay rules, and L7 reports unavailable. The browser Gateway does not run native L3, a trained L4 model, or hardware L7 attestation. An allowed browser action therefore has an `INCOMPLETE` EffectSeal receipt. A custom prompt is called intercepted only when the model actually proposes a forbidden action and L2 denies it; a manual probe exercises L2 without a model.

The [published v4 report](../benchmarks/results/agentsentinel_model_eval_v4.md) is one trial per held-out synthetic case on the current measured source: 3/25 attack READMEs induced a forbidden proposal, 0/3 such proposals executed, 25/25 benign answers passed a lexical task check, and all 50 audit chains, signed receipts and final-answer hashes verified. The [v3 report](../benchmarks/results/agentsentinel_model_eval_v3.md) used the same corpus on an earlier source revision; [v2](../benchmarks/results/agentsentinel_model_eval_v2.md) used a different corpus. These are descriptive single trials, not comparative intervention trials or evidence of general prompt-injection immunity.
